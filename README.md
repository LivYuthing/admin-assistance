# Admin Assistance - PMO Document Management

ระบบจัดการเอกสาร PMO (Project Management Office) สำหรับการบริหารโครงการ

## โครงสร้างเอกสาร

```
admin-assistance/
├── README.md
├── templates/
│   ├── project-charter.md
│   ├── status-report.md
│   └── risk-register.md
├── projects/
│   └── (โฟลเดอร์สำหรับแต่ละโครงการ)
└── docs/
    └── pmo-guidelines.md
```

## เนื้อหา

- **templates/** - แม่แบบเอกสารมาตรฐาน PMO
- **projects/** - เอกสารของแต่ละโครงการ
- **docs/** - คู่มือและแนวทางปฏิบัติ PMO

## การใช้งาน

1. เลือก template ที่ต้องการจาก `templates/`
2. คัดลอกไปยังโฟลเดอร์โครงการใน `projects/`
3. กรอกข้อมูลให้ครบถ้วน
4. ส่งเอกสารตาม approval process
